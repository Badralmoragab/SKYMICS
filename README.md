# Smart Control System Integration for Home Assistant 🚀

تكامل مخصص وشامل لإدارة أنظمة التحكم الذكي لشركة **Smart Control Co.** عبر بروتوكول MQTT.

## 🌟 المميزات
- **إعداد تلقائي بالكامل:** تسجيل وتفعيل 151 ريلاي (Relay 1 to Relay 151) بنقرة واحدة.
- **دعم حساسات البيئة:** قراءة وتحديث درجات الحرارة والرطوبة تلقائياً.
- **واجهة تفاعلية ومحاكاة منزلية:** داشبورد مخصص يحتوي على تأثيرات بصرية (مثل انبعاث الهواء البارد الأزرق للمكيفات ومؤشرات اللمس).
- **سهولة التعديل والتخصيص:** إمكانية إعادة تسمية السويتشات ونقلها بين الغرف من واجهة Home Assistant دون الحاجة لتعديل الكود.

## 📦 طريقة التثبيت عبر HACS
1. افتح **HACS** داخل Home Assistant.
2. اضغط على النقاط الثلاث في الأعلى ثم اختر **Custom repositories**.
3. أضف رابط هذا المستودع وحدد النوع كـ **Integration**.
4. اضغط على **Install** ثم أعد تشغيل Home Assistant.
5. اذهب إلى **Settings > Devices & Services > Add Integration** وابحث عن **Smart Control System**.
